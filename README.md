### A writeup on this topic is available as a [blog post on my website](https://marcoshuerta.com/posts/full-moon-myth/).

This is code for analyzing data from retrosheets.org and other sources and merge with lunar phase data to debunk the Google Cloud Gemini ad purporting to show a siginifcant change in certain baseball stats during the full moon.

Future uses of the code here are a "p-hacking" bot (and associated web app) that will post random "significant" stats that occur during various phases of the moon.
